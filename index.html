Transportation Network Optimization

Ringpu Biology · Summer 2026

Ringpu runs a national shipment network for veterinary biologics. Its carrier contracts price by lane and volume, so route choice and consolidation have to be solved together rather than lane by lane.

What I built
  • A path-based mixed-integer program on a time-expanded network, with path flow variables and piecewise linear performance pricing for carrier tiers.
  • A packaging should-cost model and total-cost-of-ownership comparison to test whether supplier price increases were justified against rubber market indices.
  • The scenario runs the team used during the logistics arm's consolidation, comparing network designs across demand and rate assumptions.
  • Python
  • AMPL
  • MILP
  • Time-expanded networks
  • TCO / should-cost
Code is proprietary to Ringpu; I can walk through the model on request.

Desktop Operations Dashboard

Personal project · 2026

A calendar and task dashboard that sits directly on the Windows desktop instead of in a browser tab, because a widget you have to open is a widget you stop using.

What I built
  • A Tkinter and Win32 application that embeds its panels behind desktop icons and paints through a color-keyed layered window.
  • CalDAV sync with recurring-event expansion, drag to reschedule, and a task strip fed from a local cache.
  • A wallpaper-aware rendering pipeline so the glass panels blend with whatever background is in use, plus a watchdog that restarts the panels if they die.
  • Python
  • Tkinter
  • Win32 API
  • CalDAV
  • PIL
