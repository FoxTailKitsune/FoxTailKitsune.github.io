# Joseph Wang — Personal Portfolio

Personal portfolio site for Joseph Wang, built as the Week 8 portfolio assignment
(Conquering Your Transition, 33:011:303).

**Live site:** https://foxtailkitsune.github.io/

## Sections

- Personal statement
- Skills
- Projects (transportation network optimization, AI financial chatbot, store operations improvement)
- Education

## Stack

Single static `index.html`, no build step and no external dependencies. Styles are
inline in the document; the only script sets the copyright year.

## Run locally

Open `index.html` in any browser, or serve the folder:

```bash
python -m http.server 8000
```
